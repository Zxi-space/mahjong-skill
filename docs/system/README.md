# 雀变 Mahjong Skill｜开发文档 V1.3（2026-10-30 新三端设计稿）

> 此包是基于已批准 V1.0 玩法规则、旧 V1.2 总规范与 2026-10-30 最新三张视觉设计稿的**文档修订版**，不代表开发进度已完成。

## 最重要的结论

1. **新的视觉事实源**：`references/01-client-approved-20261030.webp`、`02-portal-approved-20261030.webp`、`03-admin-approved-20261030.webp`。旧视觉稿失去当前验收效力。
2. **产品定位永久不变**：线下实体麻将的电子技能卡辅助工具；不开发在线实体麻将手牌、摸牌/出牌、麻将牌墙/牌河/对局模拟、胡牌与计分。
3. **品牌 IP 不变**：雀叽家族七位“拟人化麻将牌”，不允许鸡、鸟或其他动物替代。风格为极简线条手绘、奶油白+深麻将绿+柔和彩色类别。
4. **规则与优先级不变**：原 V1.0 24 张官方概念牌、15 个预设效果模板；P0 实现经典卡盒/联网技能房间，P1 用户自定义，P2 后续生态。
5. **三端结构**：`frontend/client` (Taro Mini/H5) / `frontend/admin` (React+Vite) / `frontend/portal` (Next.js) / `backend` (FastAPI)，三个前端暂不建共享业务组件包。
6. **Light/Dark**：三端都支持 Light/Dark/跟随系统；2026-10-30 三张批准的是 Light，Dark 需要按新稿同布局继续出稿并验收。

### 本次修订范围

- 更新的只有 **视觉与工程落地约束**；没有擅自创建新玩法，没有把会员、线上麻将、卡牌商城等设计展示当成 P0 已批准需求。
- 没有修改原阶段数量与 P0/P1/P2 核心归属；继续支持“经典卡盒单设备”与“四人电子技能房间”。
- 老文档的合订本重复全文、以及原三张各 2～3MB PNG，不在本包重复打包；只有三张单份 WebP 参考。
- **所有组件/素材/页面状态均为计划与规范**，不表示它们已经完成生产、开发、联调或上线。

### 定义澄清

原 V1.0 玩法规则中“私有手牌”的历史用语专指玩家拥有的**电子技能牌集合**。为避免误会，实际 UI 使用“我的技能卡 / 本局技能卡 / 已使用的技能卡”，严禁“我的麻将手牌”。
